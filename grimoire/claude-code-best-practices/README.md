# Claude Code Best Practices 🧙‍♂️

Welcome to the collection of best practices and guides for working with **Claude Code**. This grimoire is designed to help you harness the full power of agentic coding with a focus on efficiency, safety, and modern protocols.

## 🚀 Getting Started

To get started with Claude Code, you need to install the CLI tool globally via npm:

```bash
npm install -g @anthropic-ai/claude-code
```

## 📖 Contents

This folder contains the following guides:

- **[Model Context Protocol (MCP)](./mcp.md)**: A comprehensive guide on configuring and managing MCP servers, including CLI commands and useful server examples.
- **[Sub-Agents](./sub-agents.md)**: Best practices for leveraging sub-agents within your development workflow (Work in Progress).

## 🛠️ Key Concepts

- **Agentic Workflows**: Moving beyond simple chat to autonomous task execution.
- **MCP Integration**: Extending Claude's capabilities with external tools and data sources.
- **Sub-Agent Orchestration**: Breaking down complex tasks into manageable sub-tasks for better accuracy.
